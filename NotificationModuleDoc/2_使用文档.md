# Android通知消息抓取模块 - 完整使用文档

## 📚 模块概述

本模块是一个独立的Android通知消息抓取和筛选模块，具有以下特点：
- ✅ 完全独立，不修改项目原有文件
- ✅ 从系统通知栏抓取消息数据
- ✅ 支持灵活的筛选规则
- ✅ 返回可读的String字符串
- ✅ 自动输出详细的日志
- ✅ 支持局部单独测试

---

## 📁 模块文件结构

```
app/src/main/java/com/jushi/demo/main/utils/
├── MessageModel.java              # 消息数据模型
├── NotificationFilter.java        # 筛选器接口和实现
├── NotificationCaptureService.java # 捕获服务（核心）
├── NotificationModuleAPI.java     # 对外接口API ⭐
└── NotificationModuleTest.java    # 独立测试类
```

---

## 🏗️ 架构设计

```
【四层架构】

应用层 (主程序)
    ↓
API层 (NotificationModuleAPI)  ← 主程序只需调用此层
    ↓
服务层 (NotificationCaptureService) + 筛选层 (NotificationFilter)
    ↓
数据层 (MessageModel)
```

---

### 2️⃣ 获取所有消息

```java
String allMessages = api.captureAllMessagesAsString();
```

---

### 3️⃣ 自定义规则筛选 ⭐推荐

```java
// 按包名和群聊名称筛选
String result = api.filterLatestMessageByRule(
    "com.tencent.mm",      // 目标包名（null表示不筛选）
    "人工智能课程"         // 目标群聊名称（null表示不筛选）
);
```

**参数说明：**
- `targetPackageName`：应用包名，null时不筛选包名
- `targetGroupName`：群聊名称，null时不筛选群聊名称

**使用示例：**
```java
// 筛选微信所有消息
api.filterLatestMessageByRule("com.tencent.mm", null);

// 筛选微信特定群聊
api.filterLatestMessageByRule("com.tencent.mm", "人工智能课程");

// 筛选任何应用的特定群聊
api.filterLatestMessageByRule(null, "人工智能课程");

// 同时筛选包名和群聊
api.filterLatestMessageByRule("com.tencent.mm", "AI课程");
```

---

### 4️⃣ 筛选微信消息

```java
// 筛选所有微信消息
String allWeChat = api.filterWeChatMessage(null);

// 筛选微信特定群聊
String wechatGroup = api.filterWeChatMessage("人工智能课程");
```

---

### 5️⃣ 筛选AI课程群消息

```java
// 自动检测包含"人工智能"、"AI课程"等关键字的消息
String aiMessage = api.filterAICourseGroupMessage();
```

---

### 6️⃣ 筛选微信AI课程群消息 ⭐常用

```java
// 组合条件：微信应用 + AI课程群
String result = api.filterWeChatAICourseMessage();
```

这是最常用的接口，自动处理默认的微信和AI课程群筛选。

### 7️⃣ 高级接口

## 📊 消息数据模型

`MessageModel` 包含以下字段：

```java
String packageName     // 应用包名（如："com.tencent.mm"）
String appName         // 应用名称
String title           // 消息标题
String content         // 消息内容
String groupName       // 群组名称（仅限聊天应用）
String senderName      // 发送者名称
long timestamp         // 消息时间戳
int notificationId     // 系统通知ID
```

**常用方法：**

```java
message.toString()        // 格式化字符串输出
message.toSimpleString()  // 简洁字符串："[包名] 标题 - 内容"
message.toJsonString()    // JSON格式字符串
```

## 🔧 扩展和定制

### 创建自定义筛选器

```java
public class MyCustomFilter implements NotificationFilter.IMessageFilter {
    @Override
    public boolean match(MessageModel message) {
        // 自定义筛选逻辑
        return message.getContent().contains("关键字");
    }
}

// 使用
MyCustomFilter myFilter = new MyCustomFilter();
api.setCustomFilter(myFilter);
```

### 使用复合筛选器（AND逻辑）

```java
List<NotificationFilter.IMessageFilter> filters = new ArrayList<>();
filters.add(new NotificationFilter.PackageNameFilter("com.tencent.mm"));
filters.add(new NotificationFilter.GroupNameFilter("AI课程"));

NotificationFilter.CompositeAndFilter andFilter = 
    new NotificationFilter.CompositeAndFilter(filters);
api.setCustomFilter(andFilter);
```

## 🐛 常见问题

**Q: 为什么获取不到消息？**
A: 
1. 确保手机有活跃的通知（发送短信或其他应用通知）
2. 检查权限是否已授予
3. 查看 Logcat 中的错误日志

**Q: 如何在后台持续监听消息？**
A: 使用 Service 或定时任务定期调用接口

**Q: 如何获取特定应用的通知？**
A: 使用 `filterLatestMessageByRule(packageName, null)`

**Q: 如何自定义筛选逻辑？**
A: 实现 `IMessageFilter` 接口或使用 `CustomRuleFilter`

**Q: 支持哪些Android版本？**
A: Android 6.0+，推荐Android 8.0+
