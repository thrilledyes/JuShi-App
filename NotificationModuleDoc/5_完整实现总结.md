## 📦 创建的文件清单

### 核心模块文件 (5个)

位置：`app/src/main/java/com/jushi/demo/main/utils/`

1. **MessageModel.java**
   - 消息数据模型
   - 包含8个字段：包名、标题、内容、群聊名等
   - 提供多种输出格式：toString()、toSimpleString()、toJsonString()

2. **NotificationFilter.java**
   - 消息筛选器接口和实现
   - 包含7个筛选器类：
     - IMessageFilter (接口)
     - PackageNameFilter (包名筛选)
     - GroupNameFilter (群聊筛选)
     - WeChatFilter (微信预设)
     - AICourseGroupFilter (AI课程预设)
     - CustomRuleFilter (自定义规则)
     - CompositeAndFilter / CompositeOrFilter (复合筛选)

3. **NotificationCaptureService.java**
   - 核心消息捕获服务
   - 职责：获取系统通知 → 提取数据 → 转换为MessageModel → 应用筛选
   - 关键方法：
     - captureLatestMessage() 获取最新
     - captureAllMessages() 获取所有
     - captureAndFilterLatest() 捕获并筛选
     - captureAndFilterAll() 捕获并筛选所有

4. **NotificationModuleAPI.java** ⭐ 主接口
   - 对外暴露的高级接口
   - 提供7个公共方法：
     - captureLatestMessageAsString() 基础接口
     - filterLatestMessageByRule() ⭐推荐
     - filterWeChatMessage() 预设
     - filterAICourseGroupMessage() 预设
     - filterWeChatAICourseMessage() ⭐常用

5. **NotificationModuleTest.java**
   - 独立测试类
   - 提供7个测试方法
   - 支持全量测试和单个测试
   - 可局部单独运行验证功能

## 📖 使用指南

### 基础使用 (推荐)

```java
// 创建API对象
NotificationModuleAPI api = new NotificationModuleAPI(context);

// 方式1：获取微信AI课程群消息（最常用）
String msg = api.filterWeChatAICourseMessage();

// 方式2：自定义包名和群聊筛选（最灵活）
String msg = api.filterLatestMessageByRule("com.tencent.mm", "人工智能课程");

// 方式3：获取所有消息（不筛选）
String msg = api.captureAllMessagesAsString();

// 查看结果
Log.i("MyApp", msg);
```

## 🚨 常见问题速答

**Q: 如何在我的Activity中使用？**
A: 
```java
NotificationModuleAPI api = new NotificationModuleAPI(this);
String msg = api.filterWeChatAICourseMessage();
Log.i("MyApp", msg);
```

**Q: 如何自定义筛选规则？**
A: 使用 `filterLatestMessageByRule(包名, 群聊名)` 方法

**Q: 可以只监听特定应用吗？**
A: 可以，使用 `filterLatestMessageByRule("包名", null)`

**Q: 模块会影响原有代码吗？**
A: 完全不会，模块完全独立

**Q: 如何测试模块？**
A: 使用 `NotificationModuleTest` 类运行测试

**Q: 为什么没有获取到消息？**
A: 需要先发送通知（短信、应用推送等），然后调用接口
