## 🎯 核心方法速查

### 最常用方法 ⭐⭐⭐

```java
// 创建模块
NotificationModuleAPI api = new NotificationModuleAPI(context);

// 获取微信AI课程群消息（推荐）
String result = api.filterWeChatAICourseMessage();

// 自定义包名和群聊筛选

);
```

## 📚 完整方法表

### 基础接口
| 方法 | 功能 | 返回值 |
|-----|------|--------|
| `captureLatestMessageAsString()` | 获取最新消息 | String |
| `captureAllMessagesAsString()` | 获取所有消息 | String |

### 自定义筛选 ⭐推荐
| 方法 | 功能 | 参数 | 返回值 |
|-----|------|------|--------|
| `filterLatestMessageByRule(pkg, group)` | 自定义筛选最新 | 包名, 群聊名 | String |
| `filterAllMessagesByRule(pkg, group)` | 自定义筛选所有 | 包名, 群聊名 | String |

### 预设筛选 ⭐常用
| 方法 | 功能 | 返回值 |
|-----|------|--------|
| `filterWeChatMessage(groupName)` | 微信筛选 | String |
| `filterAICourseGroupMessage()` | AI课程筛选 | String |
| `filterWeChatAICourseMessage()` | 微信AI课程 | String |

### 高级接口
| 方法 | 功能 | 返回值 |
|-----|------|--------|
| `captureLatestMessage()` | 获取原始对象 | MessageModel |
| `captureAllMessages()` | 获取对象列表 | List<MessageModel> |
| `setCustomFilter(filter)` | 设置自定义筛选 | void |

### 参数使用规则

```
filterLatestMessageByRule(pkg, group)

• pkg=null, group=null    → 返回最新的任何消息
• pkg="微信", group=null   → 返回最新的微信消息
• pkg=null, group="AI课程" → 返回最新的包含"AI课程"的任何消息
• pkg="微信", group="AI课程" → 返回微信中最新的AI课程群消息
```

## 💻 完整代码片段

### 片段1：基本集成

```java
import com.jushi.demo.main.utils.NotificationModuleAPI;
import android.os.Build;

public class MyActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        
        NotificationModuleAPI api = new NotificationModuleAPI(this);
        
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
            String msg = api.filterWeChatAICourseMessage();
            Log.i("MyApp", msg);
        }
    }
}
```

## ⚠️ 常见错误与解决

| 问题 | 原因 | 解决方案 |
|------|------|--------|
| 找不到类 | 文件没复制到正确位置 | 检查路径：utils/ |
| 返回"未捕获到消息" | 没有新通知 | 发送短信或应用通知 |
| 权限错误 | 缺少权限声明 | 添加权限到 AndroidManifest.xml |
| 返回null | 没有满足条件的消息 | 检查筛选条件是否正确 |
| 日志看不到 | 日志级别过高 | 在Logcat中调整日志级别 |
