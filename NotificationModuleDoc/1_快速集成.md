# 通知消息抓取模块 - 快速集成指南

## 🎯 30秒快速开始

### 第1步：创建API对象
```java
import com.jushi.demo.main.utils.NotificationModuleAPI;

NotificationModuleAPI api = new NotificationModuleAPI(this);
```

### 第2步：调用接口获取消息
```java
if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
    String result = api.filterWeChatAICourseMessage();
    Log.i("MyApp", result);
}
```

### 第3步：查看结果
在 Logcat 搜索 `NotificationCapture` 即可看到详细日志和返回结果。

---

## 💡 最常用的3种方式

### 方式1：筛选微信AI课程群（⭐推荐）
```java
String msg = api.filterWeChatAICourseMessage();
```

### 方式2：自定义包名和群聊筛选（⭐灵活）
```java
String msg = api.filterLatestMessageByRule(
    "com.tencent.mm",      // 目标包名（null不筛选）
    "人工智能课程"         // 目标群聊名（null不筛选）
);
```

### 方式3：获取所有消息（基础）
```java
String msg = api.captureAllMessagesAsString();
```

## 🔧 集成到你的Activity

```java
import android.os.Build;
import com.jushi.demo.main.utils.NotificationModuleAPI;

public class MainActivity extends AppCompatActivity {
    
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        
        // 初始化通知消息模块
        NotificationModuleAPI api = new NotificationModuleAPI(this);
        
        // 为按钮添加点击监听
        findViewById(R.id.btnCheckMessage).setOnClickListener(v -> {
            if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.M) {
                // 筛选微信AI课程群消息
                String message = api.filterWeChatAICourseMessage();
                Log.i("MyApp", message);
                Toast.makeText(this, "已获取消息，请查看日志", Toast.LENGTH_SHORT).show();
            }
        });
    }
}
```

## 📝 参数说明

### 常见应用包名

- 微信：`com.tencent.mm`
- QQ：`com.qq.mobileqq`
- 短信：`com.android.messaging`

### 参数使用规则

```
filterLatestMessageByRule(包名, 群聊名)

• (null, null) → 返回最新的任何消息
• ("微信", null) → 返回最新的微信消息
• (null, "群名") → 返回最新的包含群名的消息
• ("微信", "群名") → 返回微信中最新的指定群消息
```

## ⚠️ 常见问题

| 问题 | 解决方案 |
|------|--------|
| 找不到类 | 确保文件在 `app/src/main/java/com/jushi/demo/main/utils/` |
| 返回"未捕获到消息" | 先发送一条通知（短信、应用消息等） |
| 权限错误 | 检查 AndroidManifest.xml 是否包含权限 |
| 返回null | 检查筛选条件是否正确 |
